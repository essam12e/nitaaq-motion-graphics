# Rigging (layered SVG)

`svgToRig()` reads the artist's groups and builds a lightweight 2D rig. No external tool, no upload.

## Naming

Group ids / Inkscape labels / `data-name` are mapped to logical parts (English or Arabic, any case or separator):

| part | names it understands (examples) |
|---|---|
| torso | torso, body, chest, thobe, thawb, dishdasha, shirt, abaya, ثوب, جسم, بشت |
| head / neck | head, face, رأس, وجه · neck, رقبة |
| headwear | ghutra, shemagh, keffiyeh, agal, iqal, hijab, cap, غترة, شماغ, عقال, حجاب, طاقية |
| arms | upperArm L/R, lowerArm / forearm L/R, hand L/R, arm L/R, عضد, ساعد, يد, كف (+ يمين / يسار) |
| face | eyes, eyebrows, mouth, nose, beard, عين, حاجب, فم, لحية |
| legs / hips | legs, feet, shoes, ساق, قدم · hips, waist |
| props | phone, mobile, laptop, product, جوال |

Sides are **image** sides (screen left / right). Nesting in the SVG defines the hierarchy; otherwise anatomical defaults are used (hand → lower arm → upper arm → torso; headwear → head → neck → torso).

Face states: child groups with `data-state="open"` (or ids like `mouth-open`, `eyes-closed`) become swappable states (blink, talk, expressions).

Manual pivots: `data-pivot="x,y"` (viewBox units) on a group overrides detection.

## Modes

- **full** — head, both arms (upper / lower / hand), face states → FULL_VECTOR_RIG: real gestures (point with an aim angle, present, hold phone in the hand that holds it, type, shrug, hand on chin, celebrate, wave, thumbs up, stop, explain).
- **partial** — some parts (e.g. head only) → PARTIAL_RIG: head tilt / turn, blink, the rest as drawn.
- **grouped** — no recognisable parts → the whole artwork moves as one (pose-based camera and idle); never an error.

Each part's geometry is measured by rasterising it alone (transforms, clip paths and strokes included). Joint limits keep elbows and heads within natural ranges. Secondary motion: the headwear follows the head with a lag and settles (follow-through), the lower arm and hand drag behind the upper arm (overlapping action).
