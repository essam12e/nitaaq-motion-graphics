# نطاق | موشن جرافيك — NITAAQ | Motion Graphics

<div dir="rtl">

مخرج موشن جرافيك ذكي يبدأ بالعربي. تكتب طلبك بكلامك العادي، ويسلّمك فيديو MP4 جاهز بعد ما يمر على فحص جودة كامل.

```
الطلب ← أسئلة قليلة (وسؤال الشعار إذا ما فيه شعار) ← تصنيف المهمة ← تحديد نوع الفيلم
      ← تشغيل الموديولات اللي يحتاجها الفيلم بس (خرائط، موسيقى مولّدة، GSAP، تحليل الشعار، نسخ إعلانية)
      ← الهوية + المرجع + الإيقاع ← القصة ← الستوري بورد ← المخرج الإبداعي
      ← حركة النصوص + الانتقالات حسب المعنى ← مواصفة الفيديو
      ← مخرج الصوت (أحداث الحركة ← المعنى ← عائلة الصوت ← التنويعة ← التزامن ← الميكس)
      ← التحقق ← فحص هيكلي + قياس العناصر المشتركة + فحص الصوت ← إصلاح تلقائي
      ← أنيماتك ← الرندر النهائي ← فحص تقني نهائي ← MP4
      ← (اختياري) نسخ إعلانية بخمس استراتيجيات وأربع مقاسات، بإعادة تصميم مو قص
```

## التثبيت بسطر واحد (Claude Code و Codex)

انسخ هذا الأمر في الترمنال (ماك أو لينكس أو WSL على ويندوز):

```bash
curl -fsSL https://raw.githubusercontent.com/essam12e/nitaaq-motion-graphics/main/install.sh | bash
```

الأمر هذا يسوي كل شي بنفسه:
1. ينزّل السكيل في `~/.nitaaq-motion-graphics`.
2. يثبّت الحزم والخطوط ويسوي الفحص المبدئي.
3. يسجّله كسكيل في Claude Code (`~/.claude/skills`) وفي Codex (`~/.codex/skills` مع إشارة في `~/.codex/AGENTS.md`).

بعدها افتح Claude Code أو Codex واكتب: «سوي لي فيديو موشن…».

- **للتحديث:** شغّل نفس الأمر مرة ثانية.
- **لأداة وحدة بس:** أضف `bash -s -- --claude-only` أو `bash -s -- --codex-only` بدل `bash`.

وإذا تحب، تقدر ببساطة تعطي Claude Code أو Codex رابط المستودع وتقول له: «ثبّت هذا السكيل».

## التثبيت في claude.ai (رفع ملف)

1. نزّل الملف من هذا الرابط: [nitaaq-motion-graphics-claude-ai.zip](https://github.com/essam12e/nitaaq-motion-graphics/raw/main/dist/nitaaq-motion-graphics-claude-ai.zip)
2. افتح claude.ai، وروح **Settings ← Capabilities ← Skills**، واضغط **Upload skill**، وارفع الملف.
3. فعّل **تنفيذ الأكواد** وخلّه يوصل للإنترنت، لأنه يحتاج يثبّت الحزم أول مرة.

هذي نسخة مخففة فيها أقل من ٢٠٠ ملف، وهو الحد اللي يقبله claude.ai. الخطوط تنزل تلقائياً وقت التجهيز. وإذا عدّلت على الكود، تقدر تعيد بناء الملف بالأمر `./cli/pack-claude-ai.sh`.

## المميزات

**مخرج واحد وموديولات تتحمّل وقت الحاجة.** يتعرف على نوع الفيلم (إعلان، منتج، إطلاق، شعار، تايبوغرافي، بيانات، خريطة، شرح، وايت بورد، رسوم توضيحية، واجهة موقع) ويشغّل بس الموديولات اللي يحتاجها. التفاصيل في [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

**الحركة**
- **محرك مبادئ الأنيميشن:** الكتلة الظاهرة، التمهيد قبل الحركة، التجاوز المحسوب، التتابع، المسارات المنحنية للعناصر العضوية، والضغط والتمدد للعناصر الخفيفة بس. ١٢ إعداد فيزياء مقاس. التفاصيل في [docs/MOTION_SYSTEM.md](docs/MOTION_SYSTEM.md).
- **حركة النصوص:** ٢٧ عائلة. العربي ما يتقطع حرف حرف أبداً، ولا يتباعد بين الحروف، ويتحرك بالكلمة أو مجموعة الكلمات. وما تتكرر نفس حركة العنوان في مشهدين ورا بعض. التفاصيل في [docs/TEXT_MOTION.md](docs/TEXT_MOTION.md).
- **الانتقالات حسب المعنى:** ٣٠ انتقال، ويختار حسب العلاقة بين المشهدين (كشف، تباين، استمرارية، إيقاع)، مع ميزانية للانتقالات اللافتة. والعنصر المشترك (شعار، منتج، شاشة) ينتقل بين المشهدين كعنصر واحد بعد ما يقيس مكانه الحقيقي. التفاصيل في [docs/TRANSITIONS.md](docs/TRANSITIONS.md).

**أنواع الأفلام**
- **أنيميشن الشعار:** يحلل تركيب الشعار ويختار طريقة الظهور المناسبة، وما يشوّه الشعار أبداً. وهوية الحركة تنحفظ في `brand-motion.json` عشان الأفلام الجاية تكون متناسقة. التفاصيل في [docs/BRAND_MOTION.md](docs/BRAND_MOTION.md).
- **منتجات ومتاجر:** صورة المنتج ما تتعدل أبداً. التفاصيل في [docs/PRODUCT_VIDEO.md](docs/PRODUCT_VIDEO.md).
- **أفلام الإطلاق والحماس:** تشويق ← كشف ← تفاصيل ← دعوة. التفاصيل في [docs/LAUNCH_FILM.md](docs/LAUNCH_FILM.md).
- **نسخ إعلانية:** خمس استراتيجيات (المشكلة أولاً، المنتج أولاً، الفائدة أولاً، العرض أولاً، النتيجة أولاً) بمقاسات 9:16 و4:5 و1:1 و16:9. التفاصيل في [docs/AD_VARIANTS.md](docs/AD_VARIANTS.md).
- **بيانات وخرائط:** رسوم بيانية وعدّادات من أرقامك بس، وخرائط من بيانات GeoJSON حقيقية. ما يخترع أي رقم أو موقع. التفاصيل في [docs/DATA_ANIMATION.md](docs/DATA_ANIMATION.md) و[docs/MAP_ANIMATION.md](docs/MAP_ANIMATION.md).
- **رسوم توضيحية ووايت بورد وأنيميشن بدون ملفات:** رسوم متجهة تتولد بالكود. التفاصيل في [docs/ILLUSTRATION.md](docs/ILLUSTRATION.md) و[docs/WHITEBOARD.md](docs/WHITEBOARD.md).
- **GSAP اختياري:** يتحمّل بس إذا احتاجه الفيلم، ونتيجته ثابتة في كل رندر. التفاصيل في [docs/GSAP.md](docs/GSAP.md).
- **١٠٢ عائلة مشاهد فيها ٢٩٥ تنويعة،** و**٢٤ ستايل** تتغيّر بألوان هويتك. التفاصيل في [docs/SCENE_LIBRARY.md](docs/SCENE_LIBRARY.md) و[docs/STYLE_LIBRARY.md](docs/STYLE_LIBRARY.md).
- **مكتبة الأساليب v2:** ٢١ أسلوبًا بصريًا (سويسري، متساوي القياس، تحريري، فيكتور مسطح، سائل، فخامة بسيطة، طاقة رياضية…). الأسلوب يغيّر التكوين والأشكال والخامة والخط والحركة والكاميرا والانتقالات وحركة توقيع خاصة، ولا يلمس المنتج أو الشعار. اكتب اسمه في `brief.style` أو اتركه يُختار تلقائيًا مع سبب الاختيار في `style_recipe.json`. القائمة: `npx tsx cli/style.ts list`. التفاصيل في [docs/STYLE_LIBRARY_V2.md](docs/STYLE_LIBRARY_V2.md).
- **فيديوهاتك داخل الفيلم:** ترسل MP4 أو MOV أو WebM، فيُحفظ الأصل كما هو، ويُوحَّد عند الحاجة، ويُختار أفضل مقطع بالقياس (مو من الثانية صفر). تقدر تحدد القص والسرعة والتكرار، ويظهر الفيديو في بطاقة أو قناع أو ملء الشاشة أو حتى ٤ فيديوهات مع بعض، وكل فريم محسوب من زمن الفيلم بالضبط. التفاصيل في [docs/VIDEO_MEDIA.md](docs/VIDEO_MEDIA.md).
- **ملفات Lottie داخل الفيلم:** ترسل شعارك أو أيقونتك أو أي حركة بصيغة ‎.json‎ أو ‎.lottie‎، فيُحفظ الأصل كما هو وتتحرك بسرعتها الحقيقية فريمًا بفريم مع زمن الفيلم. تقدر تختار مقطعًا بالاسم (marker) أو بالثواني، مع تكرار وسرعة وتأخير. الملفات اللي فيها expressions تُرفض بسبب واضح لأنها ما تعطي نفس النتيجة كل مرة. التفاصيل في [docs/LOTTIE_MEDIA.md](docs/LOTTIE_MEDIA.md).
- **رسوم SVG تتحرك من هندستها الحقيقية:** ترسل رسمتك بصيغة ‎.svg‎ (نوعها ‎svg‎)، فيُحفظ الأصل كما هو وتُرسم خطوطها كأن يدًا ترسمها ثم تتعبّأ ألوانها، أو تتجمّع مجموعاتها من مراكزها، أو تتحوّل شكلًا شكلًا إلى رسمة ثانية مع امتزاج الألوان والتدرّجات. القص والأقنعة والتدرّجات محفوظة، والسكربتات والروابط الخارجية تُحذف من نسخة العرض فقط. وفيه رسم إجرائي غير هدّام (أشكال وتحويلات وعمليات دمج وطرح وأقنعة وتعبئة وخطوط وتأثيرات، وكلها قابلة للتحريك بالمفاتيح). شعار SVG العادي يبقى كما كان. التفاصيل في [docs/VECTOR_ENGINE.md](docs/VECTOR_ENGINE.md).
- **لحظة كاملة على خط زمني واحد (Choreography):** بدل ما تتحرك العناصر كل واحد لحاله، توصف اللحظة كلها: المؤشر يقترب ← يقف فوق المجلد ← يضغط فينضغط المجلد ← صوت النقرة ← نبضة ضوء ← يفتح المجلد ← تطلع بطاقات الفيديو ← الكاميرا تقترب ← ينتقل التركيز للبطاقات. فيه تتابع وتوازي وتداخل وانتظار وعلامات وإشارات وتتبّع وتسليم، وكله يتحوّل لدوال ثابتة لكل فريم. الصوت والكاميرا يقرأون من نفس الخط، فالنقرة تنسمع في نفس الفريم اللي ينضغط فيه الزر. المؤشر القديم يشتغل كما كان، وصار يدعم الوقوف والضغط والإفلات والسحب، والعنصر المستهدف يتفاعل معه. التفاصيل في [docs/CHOREOGRAPHY.md](docs/CHOREOGRAPHY.md).
- **زجاج حقيقي ومعرض فيديو في المكان (Glass + Spatial):** طبقات زجاج فيها تغبيش وسماكة وحافة مضيئة ولمعة تمر على السطح وانكسار ضوء وحافة لونية، وانعكاساتها تتحرك مع الكاميرا. مجلد أعمال زجاجي بست حالات (مغلق، وقوف، ضغط، يفتح، مفتوح، طبقات منفصلة) تخرج منه بطاقات فيديو. ومعرض يعرض عدة فيديوهات تشتغل معًا على بطاقات في العمق، والكاميرا تتنقل بينها وتمر بجانبها. التفاصيل في [docs/SPATIAL.md](docs/SPATIAL.md).
- **كاميرا تفهم الهدف (Camera Solver):** بدل أرقام يدوية، تعطي الكاميرا عنصرًا أو مجموعة عناصر فتؤطّرها بنفسها، وتنتقل بينها بنعومة، وتبقى داخل حدود المشهد. فيها قوالب جاهزة (كشف البطل، دوران حول المنتج، عبور الكاميرا عبر المشهد، سحب التركيز…)، ومرور الكاميرا عبر الطبقات وهي تتلاشى قبل العدسة، وتمويه حركة حسب سرعة الكاميرا. وثمانية انتقالات مكانية جديدة: الدفع عبر البطاقة، القص المطابق للفيديو، مسح ببطاقة أمامية، مسح بلوح زجاج، مطابقة الحجم، عبور العمق، تمويه اتجاهي، وتسليم التركيز. التفاصيل في [docs/CAMERA.md](docs/CAMERA.md) و[docs/TRANSITIONS.md](docs/TRANSITIONS.md).
- **مؤثرات دقيقة (Micro FX):** تسعة مؤثرات خفيفة (انفجار صغير، تموّج، حلقة، شرر، أثر حركة، خطوط اصطدام، نبضة طاقة، نبضة توهّج، خطوط اتجاهية) تثبّت اللحظة ولا تزحمها. ثابتة النتيجة في كل رندر، تختارها نية الحركة وشخصية الفيلم، ولها ميزانية تمنع الإفراط. التفاصيل في [docs/MICRO_FX.md](docs/MICRO_FX.md).
- **أتمتة الصوت:** منحنيات مستوى للموسيقى، خفض تحت الصوت بأشكال مختلفة، دخول الموسيقى قبل اللحظة، تسليم من التعليق الصوتي للموسيقى، تداخل بين مقطعين موسيقيين، ونهايات ناعمة حسب شخصية الفيلم. التفاصيل في [docs/SOUND_DIRECTOR.md](docs/SOUND_DIRECTOR.md).
- **فحص مكاني (Spatial QC):** يتأكد أن البطل ظاهر ولا تغطيه طبقة أمامية، وأن الكاميرا لا تقترب حتى تتجاوز العدسة، وأن الشعار داخل المنطقة الآمنة، وأن الانتقال لا يرجع العين عكس حركته، ويحسب درجة استمرارية الحركة بين المشاهد، ويراقب ميزانية الأداء والمؤثرات، في 9:16 و16:9. التفاصيل في [docs/QUALITY.md](docs/QUALITY.md).

**الشخصيات (محرك حركة الشخصيات)**
- **الشخصية ممثل مو ديكور:** تعطيه شخصيتك (ورقة شخصية فيها عدة وضعيات، أو صور PNG لكل وضعية، أو SVG بطبقات، أو صورة وحدة)، ويحللها محلياً ويبني لها «كتاب شخصية» ومكتبة وضعيات، ويحفظها في الكاش عشان المرة الجاية ما يعيد التحليل.
- **مخرج الشخصية يقرأ كل جملة:** «وش الحل؟» سؤال، «شوف هنا» إشارة، «وصلتني رسالة» نظرة للجوال، «حمّل التطبيق» تقديم. ويختار الوضعية وحجم اللقطة والكاميرا ونوع القطع بين الوضعيات (قطع متطابق، قطع مع الكاميرا، قطع سريع، قطع على الحركة). ما يدمج وضعيتين ببعض أبداً.
- **الممثل ينفّذ بمبادئ الأنيميشن:** تمهيد قبل الحركة، تجاوز محسوب، تأخر الساعد واليد عن الذراع، الشماغ يلحق الراس ويستقر، رمش وتنفس، وحركة كلام.
- **هوية الشخصية مقفلة:** نفس الوجه والألوان والمقاسات في كل لقطة. والثوب والشماغ والعقال ما تتغير ولا تتلوّن ولا تتمدد.
- **مشاهد جاهزة:** الشخصية تتكلم أو تشير للنص، تمسك الجوال (بنفس اليد اللي فيها الجوال) مع شاشة تطبيق أو محادثة، تقدّم منتجك، تشرح رقمك أو رسمك البياني مع المصدر، وتختم بدعوة.
- **صادق مع الصورة الوحدة:** إذا أعطيته صورة وحدة يحركها بالكاميرا والإطار والتنفس، وما يخترع إشارة يد أو تعبير مو موجود في الرسم.
- **محلي بالكامل:** ما يرفع رسوماتك لأي خدمة، وما يحتاج أي API مدفوع.
- التفاصيل في [docs/CHARACTER_ENGINE.md](docs/CHARACTER_ENGINE.md) وباقي ملفات `docs/CHARACTER_*.md`.

**الصوت**
- **مخرج صوت ذكي:** كل مؤثر صوتي مبني على حدث حركة حقيقي ووقته الفعلي (لحظة الاصطدام أو الاستقرار مثلاً)، مو على بداية المشهد. فيه ٣٢ عائلة و١٨٠ تنويعة مولّدة بالكود، وشخصية صوت، وميزانية كثافة (الصمت جزء من التصميم)، وما يتكرر نفس الصوت ورا بعض ولا بين الأفلام المتتالية (`sfx-history.json`). التفاصيل في [docs/SOUND_DIRECTOR.md](docs/SOUND_DIRECTOR.md).
- **موسيقى:** الأولوية لموسيقاك، بعدها موسيقى مرخصة، بعدها موسيقى مولّدة بالكود مبنية على قصة الفيلم (ضربة على لحظة البطل)، وإلا بدون. **ما يحمّل أي موسيقى محمية.** التفاصيل في [docs/AUDIO.md](docs/AUDIO.md).
- **التعليق الصوتي:** بدون صوت (الافتراضي)، أو تسجيلك والمشاهد متزامنة مع عباراتك، أو صوت احترافي بس إذا طلبته (بدون صوت روبوتي بديل).

**الإخراج بطبقات (Stage → Film → Art Director)**
- **وضع المسرح:** عالم واحد مترابط بدل صف مشاهد. العناصر تبقى بين اللقطات، وكل حركة كاميرا لها سبب. التفاصيل في [docs/STAGE.md](docs/STAGE.md).
- **مخرج الفيلم:** يخطط للفيلم كله: منحنى الطاقة، motif يرجع في النهاية، وكل قطع له خطة وفحص. التفاصيل في [docs/FILM_DIRECTOR.md](docs/FILM_DIRECTOR.md).
- **المدير الفني للحركة:** يسأل لكل لقطة "وش الحدث البصري؟". يجرّب ٢–٤ حلول لكل مشكلة، ويرندرها فعليًا، ويقيسها بالبكسل، ويختار فقط اللي تتفوق فعلًا على النسخة الحالية. الدائرة ممكن تصير زر الـCTA نفسه (`become`)، وأصولك (صورك وشاشاتك) ما تتغير أبدًا. التفاصيل في [docs/ART_DIRECTOR.md](docs/ART_DIRECTOR.md).

**الجودة والأداء**
- **فحص بمراحل:** هيكل، تصميم، حركة، صوت، ثم فحص تقني على ملف MP4، مع إصلاح تلقائي. التفاصيل في [docs/QUALITY.md](docs/QUALITY.md).
- **خلفيات نظيفة:** بدون نقاط وشبكات وجزيئات إلا إذا طلبتها صراحة، وسجل للأشكال المستهلكة الممنوعة في `design/banned-patterns.json`.
- **عربي صحيح:** RTL سليم، حروف متصلة، ترقيم عربي، خلط سليم مع الإنجليزي، والنص ما ينقص بدون تنبيه.
- **سرعة مقاسة:** كاش لكل شي ثقيل، وأنيماتك ولوحة لقطات قبل الرندر، و`performance_report.json` لكل تشغيل. التفاصيل في [docs/PERFORMANCE.md](docs/PERFORMANCE.md).
- **بدون أي علامة مائية،** ولا اسم أداة أو مطوّر حتى داخل بيانات ملف MP4.
- **ذاكرة للمشروع ومحرر Motion Studio** للمعاينة والتعديل.

## التثبيت

المتطلبات:
- Node بإصدار 18.18 أو أحدث.
- ffmpeg: يستخدم الموجود على جهازك، وإذا ما لقاه يستخدم النسخة اللي تجي مع Remotion.
- متصفح كروم بدون واجهة: يلقاه تلقائياً، أو يحمّله Remotion أول مرة.


## كيف تعطيه شخصيتك

أضف `character` في ملف الطلب، والأسطر في `content.characterScript`:

```json
"character": { "sheet": "abu-fahad-sheet.png", "name": "أبو فهد", "saveAs": "abu-fahad" },
"content": {
  "characterScript": [
    { "line": "تعبت من الزحمة كل يوم؟" },
    { "line": "وش الحل؟" },
    { "line": "تطبيق مشوار يوصلك بسرعة", "scene": "phone" },
    { "line": "حمّل التطبيق الآن", "scene": "cta" }
  ]
}
```

- **ورقة شخصية:** `"sheet"`. الأفضل ٨ إلى ١٢ وضعية: عادي، مبسوط، متفاجئ، محتار، يفكر، يتكلم، يشير، يقدّم، ماسك جوال، يطالع الجوال، متحمس، يسمع. مو لازم كلها.
- **صور وضعيات:** `"poses": [{ "path": "pointing.png" }, ...]`.
- **SVG بطبقات مسمّاة** (راس، ذراع، يد، شماغ...): `"svg"`، ويتحرك بمفاصل حقيقية.
- **صورة وحدة:** `"image"`، بحدود واضحة.
- **شخصية محفوظة:** `"use": "abu-fahad"`.
- **تحكم بكلامك:** «خلي الحركة بسيطة» `"motion": "subtle"`، «لا تحرك الوجه» `"lockFace": true`، «خلي الشخصية يمين» `"side": "right"`.

معاينة سريعة: `npx tsx cli/nitaaq.ts animatic <مجلد المشروع>` تطلع لك فيديو سريع وصفحة تمثيل `qc/character-acting.png` فيها لقطة من كل مشهد.

## كيف تعطيه شعارك أو صوتك

- **الشعار:** حط مسار ملف الشعار في ملف الطلب، أو أرسله للوكيل. ينحفظ كما هو بدون أي تعديل، وتُستخرج منه الألوان. إذا ما ذكرت الهوية يسألك سؤال واحد:
  «هل عندك شعار أو هوية بصرية تبغى نعتمدها في الفيديو؟ إذا عندك أرسل الشعار، وإذا ما عندك أكمل لك بهوية مناسبة للمحتوى.»
- **مرجع بصري:** `"reference": { "path": "ref.png" }` أو رابط موقع، ويأخذ منه المبادئ بس.
- **التعليق الصوتي:** أرسل ملفك (MP3 / WAV / M4A / AAC)، والمشاهد تنقسم على عباراتك. وإذا أرفقت النص (سطر لكل عبارة) يصير التزامن أدق.
- **صوت الذكاء الاصطناعي:** ضع `ELEVENLABS_API_KEY` أو `OPENAI_API_KEY` في متغيرات البيئة. وإذا ما فيه مزوّد، النظام يعطيك الخيارات بدل ما يستخدم صوت رديء.

## متغيرات البيئة

انسخ ملف `.env.example`.

- **المسارات:** `MOTION_WORKSPACE`، `MOTION_UPLOADS`، `MOTION_OUTPUT`، `MOTION_CACHE`.
- **الأداء:** `NITAAQ_CACHE_DIR` (مكان الكاش، الافتراضي `.cache/nitaaq-motion/`)، `NITAAQ_NO_CACHE=1` (بدون كاش)، `NITAAQ_CONCURRENCY` (عدد عمّال الرندر).
- **طبقات الإخراج:** `NITAAQ_NO_ART_DIRECTOR=1` (بدون المدير الفني)، `NITAAQ_NO_SHOT_REDESIGN=1` (بدون إعادة تصميم اللقطة، أي P4)، `NITAAQ_NO_FILM_DIRECTOR=1` (بدون مخرج الفيلم)، `NITAAQ_NO_CAMERA=1` (بدون كاميرا)، `NITAAQ_MOTION_LANGUAGE` (لغة الحركة: premium-saas أو playful أو editorial أو energetic-tech).
- **مفاتيح الصوت الاختيارية:** تُقرأ من البيئة فقط. ما تنحفظ في المشاريع ولا في السجلات، ولا ترفعها على Git أبداً.

- **مشهد جديد:** سوّ ملف داخل `src/scenes/<الفئة>/`. عرّف فيه المعرّف والإصدار والتنويعات ومخطط المحتوى والمدة والمقاسات المدعومة، ثم سجّله في السجل. المحرك نفسه ما يحتاج أي تعديل.
