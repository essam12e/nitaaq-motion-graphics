# نطاق | موشن جرافيك — NITAAQ | Motion Graphics

<div dir="rtl">

مخرج موشن جرافيك ذكي يبدأ بالعربي. تكتب طلبك بكلامك العادي، ويسلّمك فيديو MP4 جاهز بعد ما يمر على فحص جودة كامل.

```
الطلب ← أسئلة قليلة ← تصنيف المهمة (بسيطة / عادية / متقدمة / طويلة)
      ← الهوية (ألوان من الشعار) + المرجع (مبادئ من صورة أو فيديو أو موقع) + الإيقاع (من الموسيقى)
      ← القصة ← الستوري بورد ← المخرج الإبداعي (شخصية حركة واحدة، لحظة بطل، ميزانية كاميرا، مزامنة مع الإيقاع)
      ← مواصفة الفيديو ← التحقق ← فحص هيكلي سريع + لوحة لقطات ← إصلاح تلقائي
      ← أنيماتك سريع (للمهام المتقدمة) ← الرندر النهائي ← فحص تقني نهائي ← MP4
      ← (اختياري) نفس الفيلم بمقاسات ثانية، بإعادة تصميم مو قص
```

## التثبيت بسطر واحد (Claude Code و Codex)

انسخ هذا الأمر في الترمنال (ماك أو لينكس أو WSL على ويندوز):

```bash
curl -fsSL https://raw.githubusercontent.com/essam12e/nitaaq-motion-graphics/main/install.sh | bash
```

الأمر هذا يسوي كل شي بنفسه:
1. ينزّل السكيل في `~/.nitaaq-motion-graphics`.
2. يثبّت الحزم والخطوط ويسوي الفحص المبدئي.
3. يسجّله كسكيل في Claude Code (`~/.claude/skills`) وفي Codex (`~/.codex/skills` مع إشارة في `~/.codex/AGENTS.md`).

بعدها افتح Claude Code أو Codex واكتب: «سوي لي فيديو موشن…».

- **للتحديث:** شغّل نفس الأمر مرة ثانية.
- **لأداة وحدة بس:** أضف `bash -s -- --claude-only` أو `bash -s -- --codex-only` بدل `bash`.

وإذا تحب، تقدر ببساطة تعطي Claude Code أو Codex رابط المستودع وتقول له: «ثبّت هذا السكيل».

## التثبيت في claude.ai (رفع ملف)

1. نزّل الملف من هذا الرابط: [nitaaq-motion-graphics-claude-ai.zip](https://github.com/essam12e/nitaaq-motion-graphics/raw/main/dist/nitaaq-motion-graphics-claude-ai.zip)
2. افتح claude.ai، وروح **Settings ← Capabilities ← Skills**، واضغط **Upload skill**، وارفع الملف.
3. فعّل **تنفيذ الأكواد** وخلّه يوصل للإنترنت، لأنه يحتاج يثبّت الحزم أول مرة.

هذي نسخة مخففة فيها أقل من ٢٠٠ ملف، وهو الحد اللي يقبله claude.ai. الخطوط تنزل تلقائياً وقت التجهيز. وإذا عدّلت على الكود، تقدر تعيد بناء الملف بالأمر `./cli/pack-claude-ai.sh`.

## المميزات

- **مخرج إبداعي ذكي:** يخطط الفيلم كامل قبل ما يحرّك أي عنصر. يختار شخصية حركة وحدة للفيلم كله من سبع (فاخر، حماسي، مرح، رسمي، سينمائي، تقني، رياضي)، ويعطي كل مشهد "وظيفة" للحركة، ويحدد لحظة بطل وحدة، ويحط ميزانية لحركات الكاميرا، وينوّع الانتقالات. التفاصيل في [docs/MOTION_SYSTEM.md](docs/MOTION_SYSTEM.md).
- **مكتبة فيزياء للحركة:** عشر إعدادات مقاسة (snappy، heavy، premium، elastic…) مربوطة بنوع العنصر: الزر غير الكرت غير اللوحة غير الشعار.
- **٧١ عائلة مشاهد فيها ٢٠١ تنويعة،** منها عائلات جديدة للحالات: رحلة المنتج بعنصر واحد يتحوّل (state-flow)، تعبئة نموذج، سير عمل، تكاملات، جدول بيانات، تفاصيل منتج، تأكيد طلب، صفحة هبوط. لكل عائلة تكلفة رندر وتوصيات حركة. التفاصيل في [docs/SCENE_LIBRARY.md](docs/SCENE_LIBRARY.md).
- **٢١ ستايل** مبنية على قيم (tokens) تتغيّر بألوان هويتك. التفاصيل في [docs/STYLE_LIBRARY.md](docs/STYLE_LIBRARY.md).
- **خلفيات نظيفة:** شكل إلى خمسة أشكال كبيرة بدل النقاط والشبكات والجزيئات. الأنماط الممنوعة مكتوبة في `design/banned-patterns.json` وتنفحص مرتين: في المواصفة وفي البكسل. ما تظهر النقاط إلا إذا طلبتها أنت صراحة.
- **مرجع بصري:** أرسل صورة أو فيديو أو رابط موقع يعجبك، ويستخرج منه المبادئ (الألوان، الكثافة، المساحات الفاضية، الإيقاع) بدون ما ينسخ التصميم. التفاصيل في [docs/REFERENCE_SYSTEM.md](docs/REFERENCE_SYSTEM.md).
- **المقاسات:** 9:16 و16:9 و1:1 و4:5 مع المناطق الآمنة لكل منصة. وتقدر تطلب نفس الفيلم بعدة مقاسات (`formats`)، وكل مقاس يُعاد تصميمه مو مجرد قص.
- **عربي صحيح:** اتجاه RTL سليم، حروف متصلة بدون تقطيع أو تباعد، ترقيم عربي، أرقام حسب اختيارك، خلط سليم مع الإنجليزي، والنص ما ينقص أبداً بدون تنبيه. وفيه فحص قراءة على حجم شاشة الجوال.
- **الهوية البصرية:** مع شعار يستخرج لوحة ألوان بتباين آمن ويكتبها في `brand.json` مع الألوان الآمنة للقراءة على كل خلفية. بدون شعار يولّد اتجاه بصري مناسب، **وما يصمم شعار وهمي أبداً**. التفاصيل في [docs/BRAND_SYSTEM.md](docs/BRAND_SYSTEM.md).
- **الصوت:** بدون صوت (الافتراضي)، أو تسجيلك والمشاهد متزامنة مع عباراتك، أو صوت احترافي فقط إذا طلبته (بدون صوت روبوتي بديل). محرك إيقاع يحلل الموسيقى ويركّب القطعات على النبضات، وخفض ناعم للموسيقى تحت الكلام، و٢٦ مؤثر صوتي حر بفئات. التفاصيل في [docs/AUDIO.md](docs/AUDIO.md).
- **سرعة مقاسة:** كاش لكل شي ثقيل (البندل، تحليل الشعار، المرجع، الإيقاع، فحوصات الجودة، وحتى الفيديو نفسه)، وملف `performance_report.json` لكل تشغيل. التفاصيل في [docs/PERFORMANCE.md](docs/PERFORMANCE.md).
- **جودة بثلاث مراحل:** فحص هيكلي، وتصميم، وحركة، ثم فحص تقني على ملف MP4. درجات وتقييم مع اقتراح إصلاح لكل مشكلة، وإصلاح تلقائي. التفاصيل في [docs/QUALITY.md](docs/QUALITY.md).
- **ذاكرة للمشروع:** كل قرار ينكتب في ملفات داخل مجلد المشروع (`project_brief.md`، `brand.json`، `storyboard.json`، `shotlist.json`، `motion_spec.json`، `beats.json`، `quality_report.json`، `review_log.md`…) عشان أي تعديل لاحق يبني على نفس القرارات.
- **بدون أي علامة مائية:** ما فيه اسم أداة ولا مطوّر في أي مكان، ولا حتى داخل بيانات ملف MP4.
- **محرر Motion Studio:** معاينة حية، وخط زمني، ولوحة خصائص، وتراجع وإعادة، وحفظ وتحقق ورندر.

## التثبيت

المتطلبات:
- Node بإصدار 18.18 أو أحدث.
- ffmpeg: يستخدم الموجود على جهازك، وإذا ما لقاه يستخدم النسخة اللي تجي مع Remotion.
- متصفح كروم بدون واجهة: يلقاه تلقائياً، أو يحمّله Remotion أول مرة.

```bash
npm run setup        # يثبّت الحزم بـ npm ci (بس إذا تغيّر ملف القفل) + الخطوط + الفحص المبدئي
npm run preflight    # لازم ينتهي بكلمة ready (محفوظ بالكاش؛ أضف --full لفحص كامل)
```

## الاستخدام

### من Claude Code

المجلد نفسه هو السكيل، والتعليمات في ملف `SKILL.md`.

1. انقل المجلد (أو اربطه) إلى `~/.claude/skills/nitaaq-motion-graphics`، أو إلى `.claude/skills/` داخل مشروع. تقدر تسوي الربط بالأمر `./adapters/claude-code/install.sh`.
2. شغّل `npm run setup` مرة وحدة.
3. اطلب الفيديو بكلامك، مثل:
   - «أنشئ فيديو موشن»
   - «سوي لي فيديو موشن 30 ثانية لخدمة تصميم المتاجر»
   - «موشن جرافيك»
   - "Create a motion video"

   أو استدعِ السكيل مباشرة بالأمر `/nitaaq-motion-graphics`.

### من Codex

Codex يقرأ ملف `AGENTS.md` من جذر المستودع. افتح المجلد في Codex واطلب فيديو موشن، وهو يشغّل نفس الأوامر. التفاصيل في `adapters/codex/`.

### من الترمنال مباشرة

```bash
# أمر واحد من الطلب إلى الفيديو (رندر + فحص + إصلاح).
# إذا رجع برمز الخروج 2 فمعناه فيه أسئلة لازم تجاوب عليها.
npm run create -- examples/brief-tech-ad.json --out ./out --name my-ad

# خطوة بخطوة
npm run direct   -- brief.json                  # يطلع plan.json و storyboard.json و video.json
npm run validate -- workspace/projects/<id> --fix
npm run preview  -- workspace/projects/<id>     # معاينة سريعة (بدون فحص جودة)
npm run render   -- workspace/projects/<id>     # رندر نهائي + فحص + إصلاح تلقائي
npm run quality  -- workspace/projects/<id> --video file.mp4
npm run studio                                   # المحرر على http://127.0.0.1:4455

npx tsx cli/nitaaq.ts scenes | styles | voices | brand logo.png | schema-export | workspace
npx tsx cli/nitaaq.ts animatic  workspace/projects/<id>   # نسخة سريعة بنص الدقة و15 إطار لمراجعة التوقيت
npx tsx cli/nitaaq.ts recompose workspace/projects/<id> --aspects 16:9,1:1
npx tsx cli/nitaaq.ts reference ref.png | ref.mp4 | https://site
npx tsx cli/nitaaq.ts beats music.mp3
npx tsx cli/nitaaq.ts classify brief.json
npx tsx cli/nitaaq.ts cache summary | cache clear
```

فيه أمثلة جاهزة لملف الطلب في مجلد `examples/`.

**ملفات الرندر:**

| الملف | الدقة | الإطارات | الاستخدام |
|---|---|---|---|
| `preview` | نص الدقة | حسب الفيديو | نظرة سريعة |
| `animatic` | نص الدقة | 15 | مراجعة القصة والتوقيت قبل النهائي |
| `draft` | ثلاثة أرباع | حسب الفيديو | نسخة مراجعة |
| `production` | كاملة | حسب الفيديو | التسليم (CRF 18) |

كل المخرجات بصيغة H.264 وyuv420p وBT.709، والصوت AAC. وبعد الرندر يمر الملف على إعادة تغليف بدون فقد في الجودة، تحذف كل البيانات الوصفية واسم المُشفّر، عشان ما يبقى في الملف أي هوية لأداة.

## كيف تعطيه شعارك أو صوتك

- **الشعار:** حط مسار ملف الشعار في ملف الطلب، أو أرسله للوكيل. ينحفظ كما هو بدون أي تعديل، وتُستخرج منه الألوان. إذا ما ذكرت الهوية يسألك سؤال واحد:
  «هل عندك شعار أو هوية بصرية تبغى نعتمدها في الفيديو؟ إذا عندك أرسل الشعار، وإذا ما عندك أكمل لك بهوية بصرية مناسبة للمحتوى.»
- **مرجع بصري:** `"reference": { "path": "ref.png" }` أو رابط موقع، ويأخذ منه المبادئ بس.
- **التعليق الصوتي:** أرسل ملفك (MP3 / WAV / M4A / AAC)، والمشاهد تنقسم على عباراتك. وإذا أرفقت النص (سطر لكل عبارة) يصير التزامن أدق.
- **صوت الذكاء الاصطناعي:** ضع `ELEVENLABS_API_KEY` أو `OPENAI_API_KEY` في متغيرات البيئة. وإذا ما فيه مزوّد، النظام يعطيك الخيارات بدل ما يستخدم صوت رديء.

## متغيرات البيئة

انسخ ملف `.env.example`.

- **المسارات:** `MOTION_WORKSPACE`، `MOTION_UPLOADS`، `MOTION_OUTPUT`، `MOTION_CACHE`.
- **الأداء:** `NITAAQ_CACHE_DIR` (مكان الكاش، الافتراضي `.cache/nitaaq-motion/`)، `NITAAQ_NO_CACHE=1` (بدون كاش)، `NITAAQ_CONCURRENCY` (عدد عمّال الرندر).
- **مفاتيح الصوت الاختيارية:** تُقرأ من البيئة فقط. ما تنحفظ في المشاريع ولا في السجلات، ولا ترفعها على Git أبداً.

## إضافة مشهد أو ستايل جديد

- **مشهد جديد:** سوّ ملف داخل `src/scenes/<الفئة>/`. عرّف فيه المعرّف والإصدار والتنويعات ومخطط المحتوى والمدة والمقاسات المدعومة، ثم سجّله في السجل. المحرك نفسه ما يحتاج أي تعديل.
- **ستايل جديد:** أضف مجموعة قيم (tokens) في `src/styles/presets.ts`.

الشرح الكامل في [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) تحت قسم Extending.

## الاختبارات

```bash
npm run typecheck                               # فحص الأنواع
npm test                                        # اختبارات الوحدة
npm run test:visual                             # مقارنة بصرية لكل عائلة مشاهد بمقاسي 9:16 و16:9
node test/e2e/studio.e2e.mjs                    # اختبار المحرر من البداية للنهاية (يحتاج npm run studio + Playwright)
npx tsx cli/test-videos.ts --profile production # فيديوهات القبول الثمانية
npx tsx cli/dot-regression.ts                   # ما فيه نقاط ولا شبكات في أي ستايل
```

**نتائج آخر تشغيل فعلي:**
- ١٣١ اختبار وحدة: كلها نجحت.
- ١٢٦ مقارنة بصرية: كلها نجحت.
- اختبار المحرر: نجح.
- ستة فيديوهات بجودة الإنتاج: صفر أخطاء حرجة، صفر أخطاء، صفر تحذيرات.

التفاصيل والحدود المعروفة في [docs/TEST_RESULTS.md](docs/TEST_RESULTS.md).
