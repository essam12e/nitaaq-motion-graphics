# نطاق | موشن جرافيك — NITAAQ | Motion Graphics

<div dir="rtl">

مخرج موشن جرافيك ذكي يبدأ بالعربي. تكتب طلبك بكلامك العادي، ويسلّمك فيديو MP4 جاهز بعد ما يمر على فحص جودة كامل.

```
الطلب ← ملف الطلب (brief.json) ← أسئلة الاستلام ← الهوية (ألوان من الشعار، أو اتجاه بصري مولّد)
      ← الخطة الإبداعية ← الستوري بورد ← مواصفة الفيديو (video.json) ← التحقق والإصلاح
      ← الرندر (H.264) ← فحص جودة آلي (النصوص + البكسل + الصوت + ملف MP4)
      ← إصلاح تلقائي (حتى ٣ جولات) ← فيديو MP4 نهائي
```

## المميزات

- **٦٣ عائلة مشاهد فيها ١٨٥ تنويعة.** تغطي الطباعة الحركية والهوية والواجهات والجوال والمتاجر والبيانات والصور والإنفوجرافيك والمشاهد السينمائية والسوشال والدعوة للإجراء. كل عائلة إضافة مستقلة في سجل المشاهد (`SceneRegistry`)، وتفاصيلها في [docs/SCENE_LIBRARY.md](docs/SCENE_LIBRARY.md).
- **١٨ ستايل جاهز** تقدر تغيّرها بألوان هويتك. التفاصيل في [docs/STYLE_LIBRARY.md](docs/STYLE_LIBRARY.md).
- **المقاسات:** 9:16 و16:9 و1:1 و4:5، مع المناطق الآمنة لكل منصة (تيك توك، ريلز، فيد إنستقرام، شورتس، يوتيوب، وعام). التخطيط يتغيّر حسب المقاس، مو مجرد قص.
- **عربي صحيح:**
  - اتجاه RTL سليم، والحروف متصلة بدون تقطيع أو تباعد يكسرها.
  - علامات ترقيم عربية، ونظام أرقام تختاره لكل مشروع.
  - خلط سليم بين العربي والإنجليزي.
  - النص ما يطلع برا الإطار أبداً بدون ما يتم التنبيه عليه.
- **الهوية البصرية:**
  - مع شعار (PNG / JPG / WEBP / SVG): يستخرج منه لوحة ألوان بتباين آمن للقراءة.
  - بدون شعار: يولّد اتجاه بصري مناسب لمجالك، **وما يصمم شعار وهمي**.
  - التفاصيل في [docs/BRAND_SYSTEM.md](docs/BRAND_SYSTEM.md).
- **الصوت:**
  - ثلاث طرق: بدون تعليق صوتي، أو تسجيلك الصوتي والمشاهد متزامنة مع عباراته، أو صوت ذكاء اصطناعي عالي الجودة فقط (بدون أي صوت روبوتي بديل).
  - الموسيقى تدعم الظهور والاختفاء التدريجي، والتكرار، والقص، وخفض صوتها تحت التعليق.
  - فيه ٢٦ مؤثر صوتي حر الاستخدام (CC0)، وتتحكم في تشغيلها وكثافتها ومستواها.
  - التفاصيل في [docs/AUDIO.md](docs/AUDIO.md).
- **بدون أي علامة مائية:** ما فيه اسم أداة ولا اسم مطوّر في أي مكان، ولا حتى داخل بيانات ملف MP4.
- **محرر Motion Studio:** معاينة حية، وخط زمني، ولوحة خصائص، وتراجع وإعادة، وحفظ وتحقق ورندر.

## التثبيت

المتطلبات:
- Node بإصدار 18.18 أو أحدث.
- ffmpeg: يستخدم الموجود على جهازك، وإذا ما لقاه يستخدم النسخة اللي تجي مع Remotion.
- متصفح كروم بدون واجهة: يلقاه تلقائياً، أو يحمّله Remotion أول مرة.

```bash
npm run setup        # يثبّت الحزم + يجهّز الخطوط + يسوي الفحص المبدئي
npm run preflight    # لازم ينتهي بكلمة ready
```

## الاستخدام

### من Claude Code

المجلد نفسه هو السكيل، والتعليمات في ملف `SKILL.md`.

1. انقل المجلد (أو اربطه) إلى `~/.claude/skills/nitaaq-motion-graphics`، أو إلى `.claude/skills/` داخل مشروع. تقدر تسوي الربط بالأمر `./adapters/claude-code/install.sh`.
2. شغّل `npm run setup` مرة وحدة.
3. اطلب الفيديو بكلامك، مثل:
   - «أنشئ فيديو موشن»
   - «سوي لي فيديو موشن 30 ثانية لخدمة تصميم المتاجر»
   - «موشن جرافيك»
   - "Create a motion video"

   أو استدعِ السكيل مباشرة بالأمر `/nitaaq-motion-graphics`.

### من Codex

Codex يقرأ ملف `AGENTS.md` من جذر المستودع. افتح المجلد في Codex واطلب فيديو موشن، وهو يشغّل نفس الأوامر. التفاصيل في `adapters/codex/`.

### من الترمنال مباشرة

```bash
# أمر واحد من الطلب إلى الفيديو (رندر + فحص + إصلاح).
# إذا رجع برمز الخروج 2 فمعناه فيه أسئلة لازم تجاوب عليها.
npm run create -- examples/brief-tech-ad.json --out ./out --name my-ad

# خطوة بخطوة
npm run direct   -- brief.json                  # يطلع plan.json و storyboard.json و video.json
npm run validate -- workspace/projects/<id> --fix
npm run preview  -- workspace/projects/<id>     # معاينة سريعة (بدون فحص جودة)
npm run render   -- workspace/projects/<id>     # رندر نهائي + فحص + إصلاح تلقائي
npm run quality  -- workspace/projects/<id> --video file.mp4
npm run studio                                   # المحرر على http://127.0.0.1:4455

npx tsx cli/nitaaq.ts scenes | styles | voices | brand logo.png | schema-export | workspace
```

فيه أمثلة جاهزة لملف الطلب في مجلد `examples/`.

**ملفات الرندر:**

| الملف | الدقة | الجودة (CRF) |
|---|---|---|
| `preview` | نص الدقة | 28 |
| `draft` | ثلاثة أرباع الدقة | 23 |
| `production` | الدقة الكاملة | 18 |

كل المخرجات بصيغة H.264 وyuv420p وBT.709، والصوت AAC. وبعد الرندر يمر الملف على إعادة تغليف بدون فقد في الجودة، تحذف كل البيانات الوصفية واسم المُشفّر، عشان ما يبقى في الملف أي هوية لأداة.

## كيف تعطيه شعارك أو صوتك

- **الشعار:** حط مسار ملف الشعار في ملف الطلب، أو أرسله للوكيل. ينحفظ كما هو بدون أي تعديل، وتُستخرج منه الألوان.
- **التعليق الصوتي:** أرسل ملفك (MP3 / WAV / M4A / AAC)، والمشاهد تنقسم على عباراتك. وإذا أرفقت النص (سطر لكل عبارة) يصير التزامن أدق.
- **صوت الذكاء الاصطناعي:** ضع `ELEVENLABS_API_KEY` أو `OPENAI_API_KEY` في متغيرات البيئة. وإذا ما فيه مزوّد، النظام يعطيك الخيارات بدل ما يستخدم صوت رديء.

## متغيرات البيئة

انسخ ملف `.env.example`.

- **المسارات:** `MOTION_WORKSPACE`، `MOTION_UPLOADS`، `MOTION_OUTPUT`، `MOTION_CACHE`.
- **مفاتيح الصوت الاختيارية:** تُقرأ من البيئة فقط. ما تنحفظ في المشاريع ولا في السجلات، ولا ترفعها على Git أبداً.

## إضافة مشهد أو ستايل جديد

- **مشهد جديد:** سوّ ملف داخل `src/scenes/<الفئة>/`. عرّف فيه المعرّف والإصدار والتنويعات ومخطط المحتوى والمدة والمقاسات المدعومة، ثم سجّله في السجل. المحرك نفسه ما يحتاج أي تعديل.
- **ستايل جديد:** أضف مجموعة قيم (tokens) في `src/styles/presets.ts`.

الشرح الكامل في [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) تحت قسم Extending.

## الاختبارات


- ١٢٦ مقارنة بصرية: كلها نجحت.
- اختبار المحرر: نجح.
- ستة فيديوهات بجودة الإنتاج: صفر أخطاء حرجة، صفر أخطاء، صفر تحذيرات.
